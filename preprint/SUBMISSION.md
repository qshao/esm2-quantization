# arXiv submission checklist

Build: `./build.sh` → `esm2_quantization.pdf` (21 pp) and `arxiv-submission.tar.gz` (176 KB).

Upload **`arxiv-submission.tar.gz`**, not the PDF. arXiv runs its own `pdflatex`
on the source; a PDF-only submission is accepted but flagged as lower quality and
cannot be re-rendered.

## One thing left to fill in

Marked in red in the compiled PDF so it is impossible to miss.

**Data and code availability** (Section 8) — repository URL or archive DOI.
The per-variant score files are ~90 MB compressed, which is too large for
arXiv's ancillary-file allowance, so they need a Zenodo/figshare DOI or a
public repo. Everything else (code, per-assay CSVs) fits in a normal repo.

Two smaller items, neither blocking:

- **No email in the author block.** Common on arXiv and perfectly valid. Add one
  to `\author{...}` if you want a contact address in the PDF itself; the
  submission form collects one regardless.
The author block must match what you type into the arXiv submission form; a
mismatch stalls the submission in moderation.

## Verified

- Compiles standalone from the tarball alone — extracted to a clean directory
  and built with no access to this repo: 21 pages, **no undefined references or
  citations**.
- Fonts fully embedded: Type1 (LaTeX) + TrueType (figures), **no Type3**.
  Figures are generated with `pdf.fonttype 42` for exactly this reason.
- Only standard TeX Live packages: `geometry`, `booktabs`, `amsmath`,
  `graphicx`, `xcolor`, `microtype`, `caption`, `array`, `natbib`, `hyperref`,
  `algorithm`, `algpseudocode`.
- Bibliography is an inline `thebibliography`, **not** BibTeX — so there is no
  `.bbl` to ship and no chance of arXiv failing to resolve a `.bib`.
- 1 overfull hbox remains (16 pt); cosmetic, no visual defect.
- All table captions sit **above** the table body; figure captions below.

## Notes

- `\date{\today}` will stamp the build date. Freeze it to a fixed date if you
  want the PDF reproducible across rebuilds.
- Pick a license at submission time. arXiv's default (`arXiv.org perpetual,
  non-exclusive`) is the most restrictive; CC BY 4.0 is the usual choice if you
  want the figures and tables reusable.
- The title and abstract in the form must match the PDF. The abstract contains
  LaTeX math (`$p=0.34$`, `$\rho$`); arXiv's field accepts a limited subset, so
  paste a plain-text version — spell `\rho` as "rho" and drop the `$`.
